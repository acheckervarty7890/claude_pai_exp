# Build a claude_pai_exp environment that runs the SAME library versions as this
# repo's .venv_claude.
# Python 3.12 (the source venv: 3.12.3, stdlib venv off /usr/bin/python3.12)
#
# The PACKAGE SET comes from `pip freeze` of ~/Documents/claude_pai_exp/.venv —
# claude_pai_exp is the small train.py/evaluation.py probe harness, so there is
# no anthropic / claude-agent-sdk / mcp here. The VERSIONS do not: every package
# that also appears in requirements.txt is pinned to requirements.txt's version,
# so the two environments agree wherever they overlap (99 packages, of which 48
# had drifted). Do not merge the two files — the package sets differ.
#
# !! So this file DELIBERATELY DEVIATES from `pip freeze` of that venv:
#
#   1. All 99 shared packages take .venv_claude's pin. The big movers are
#      torch 2.12.1 -> 2.11.0 (with its nvidia-*/triton tail), numpy 2.5.0 ->
#      2.4.4, datasets 5.0.0 -> 4.8.4, scikit-learn 1.9.0 -> 1.8.0,
#      setuptools 81.0.0 -> 70.2.0, and:
#   2. transformers 5.12.1 -> 4.50.0, which is not a one-line change —
#      transformers 5.x is what drags in the 1.x huggingface_hub and 0.22
#      tokenizers, so all three move together or the file is unsatisfiable:
#         transformers 5.12.1 requires huggingface-hub>=1.5.0, tokenizers>=0.22.0
#         transformers 4.50.0 requires huggingface-hub<1.0,>=0.26.0,
#                                      tokenizers<0.22,>=0.21
#      The trio below (4.50.0 / 0.21.4 / 0.36.2) is the combination running in
#      .venv_claude against the same tuberlens commit, so it is known-good.
#      Nothing else in the set objects: datasets needs hf-hub<2.0,>=0.25.0,
#      accelerate >=0.21.0, tuberlens >=0.33.0 — all satisfied by 0.36.2.
#   3. kaggle is ADDED (it is not installed in that venv at all).
#
# `narwhals` is the one package pinned at the source venv's version: it is not
# in requirements.txt at all, so there was nothing to align it to.
#
# Manual setup:
#   python3.12 -m venv .venv
#   .venv/bin/pip install -U pip setuptools wheel
#   .venv/bin/pip install -e <tuberlens checkout>   # see below
#   .venv/bin/pip install -r requirements-claude_pai_exp.txt
#
# The nvidia-*/triton/cuda-* wheels are Linux+CUDA only (pulled in by torch);
# they are pinned below behind a Linux marker for exact reproduction.
